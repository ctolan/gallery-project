Context for VSCode Agent: AI Agents Landing Page on GCP
Project Overview
The goal is to build a modern, scalable, and secure landing page hosted on Google Cloud Platform that acts as a centralized access point to various AI agents, primarily hosted on N8n (an automation and workflow orchestration tool). This page will serve as a user-friendly, performant interface for interacting with these AI agents.

Framework Recommendation
For this project, consider using a modern JavaScript framework that supports server-side rendering (SSR) or static site generation (SSG) for better performance and SEO, together with ease of integration and maintenance. The two best options are:

Next.js (React-based)
Benefits:

Supports SSR and SSG out of the box.

Large community and rich ecosystem.

Easy integration with API routes, which can proxy requests securely to your AI agents.

Flexible deployment options including Vercel and GCP.

Nuxt.js (Vue-based)
Benefits:

Similar SSR and SSG capabilities as Next.js.

Great developer experience with Vue.

Modular architecture and easy integration of middleware and plugins.

Either framework can be deployed efficiently on GCP App Engine or Cloud Run with Docker containers for scalability.

Security Best Practices (Critical Priority)
Security must be integral throughout the development and deployment lifecycle to safeguard your AI agents and users. Key best practices include:

Authentication & Authorization:
Implement robust user authentication (OAuth 2.0, OpenID Connect) to control access to the landing page and underlying AI agents. Use Identity-Aware Proxy (IAP) on GCP to add another security layer for authorized access.

Secure API Communication:
Proxy API requests from the frontend to your AI agents through backend API endpoints using HTTPS with TLS encryption. Avoid exposing your AI agents' direct URLs.

Data Validation & Sanitization:
Ensure all user inputs and requests are strictly validated and sanitized on both client and server sides to prevent injection attacks.

Content Security Policy (CSP):
Apply a strict CSP header to mitigate XSS attacks by allowing only trusted sources of scripts and resources.

Use HTTPS Everywhere:
Enforce HTTPS with automatic redirects from HTTP to HTTPS using GCP’s load balancer or managed certificates.

Container and Cloud Security:
Use minimal, regularly updated container images with least privilege permissions. Use GCP’s IAM roles to restrict access to resources.
Enable Cloud Armor for DDoS protection and WAF capabilities.

Secret Management:
Store API keys, credentials, and other secrets in GCP Secret Manager instead of hardcoding them in your code or environment variables.

Logging and Monitoring:
Enable Cloud Logging and Monitoring for real-time insights, anomaly detection, and audit trails for security events.

Development Workflow Suggestions
Use VSCode with recommended extensions for Next.js/Nuxt.js and Docker to streamline development and deployment.

Develop locally with environment variables securely managed via .env files (never commit secrets).

Set up CI/CD pipelines using Cloud Build or GitHub Actions integrated with GCP to automate testing, security scans, and deploy to staging/production.

Perform regular security audits and vulnerability scans on dependencies and container images.
